# Data Engineering & Analytics Training

A hands-on professional development program focused on building practical skills in Data Engineering, Data Analytics, SQL, and Python.

## Career Objective

Develop the technical competencies required for Data Analyst and Data Engineer positions through realistic business scenarios, practical exercises, and end-to-end projects.

## Technology Stack

| Category           | Technologies                           |
| ------------------ | -------------------------------------- |
| Database           | Microsoft SQL Server                   |
| Programming        | Python                                 |
| Data Processing    | Pandas, NumPy                          |
| Data Visualization | Power BI, Matplotlib                   |
| Data Engineering   | ETL/ELT, Data Pipelines                |
| Data Warehousing   | Star Schema, Fact and Dimension Tables |
| Version Control    | Git, GitHub                            |
| Cloud              | Microsoft Azure, Databricks            |
| Big Data           | PySpark                                |
